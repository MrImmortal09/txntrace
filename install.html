First-Time Setup on iPhone:

  1. Must open this page in Safari (Apple blocks OTA installs from other browsers).
  2. Tap "Install App" and confirm "Install" when prompted.
  3. On iOS 16+, enable Developer Mode:
    Settings > Privacy & Security > Developer Mode > Turn On (restarts phone).
  4. Alternatively, upload the downloaded TxnTrace.ipa to your Signulous Dashboard or install via AltStore / Scarlet.
